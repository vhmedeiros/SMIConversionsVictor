# SMIConversionsVictor

Repositório: https://github.com/vhmedeiros/SMIConversionsVictor

Gravador de 8 canais de TV 24/7 em blocos de 4 minutos, rodando como serviço
Windows (Go). A especificação completa está em [`SPEC.md`](SPEC.md); o código
vive em [`grtv-recorder/`](grtv-recorder/) (veja o README de lá para build e uso).

Diretrizes de desenvolvimento para este repositório estão em [`CLAUDE.md`](CLAUDE.md).
